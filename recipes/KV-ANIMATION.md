# Recipe: animate an existing key visual

The objective is not to make a new scene. It is to create motion while preserving art direction.

- Bind the KV as environment/composition reference.
- State which layers are allowed to move.
- State which central objects are structurally locked.
- Use a locked camera or tiny push-in first.
- Animate particles, light, cloth, liquid or atmospheric layers before moving brand-critical geometry.
- Finish near the original composition so loops/cutdowns remain usable.
