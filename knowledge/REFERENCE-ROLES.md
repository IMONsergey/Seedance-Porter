# Reference roles

Porter treats references as production controls rather than a pile of inspiration images.

| Role | Use it for | Do not silently ask it to control |
|---|---|---|
| `identity` | face, hair, silhouette, wardrobe | camera, lighting, background |
| `product` | product geometry, materials, brand colors | text accuracy, animation style |
| `environment` | location, architecture, spatial layout | subject identity |
| `motion` | body/object movement, physical trajectory | appearance/style |
| `camera` | framing, movement path, pace | subject/action |
| `style` | lighting, grading, texture, material response | exact geometry |
| `audio` | tempo, ambience, cadence, sync cues | visual identity |
| `first_frame` | exact beginning composition/state | end state |
| `last_frame` | exact ending composition/state | beginning state |
| `endpoint` | required conceptual/visual finish | the whole shot |

## Priority strategy

For a commercial product shot, a typical priority is:

1. product identity;
2. first-frame composition;
3. camera/motion reference;
4. environment;
5. style;
6. audio.

When fidelity is poor, remove lower-priority references before adding new words.

## Reference budgets

Seedance 2.0 production routes commonly expose up to 9 images, 3 videos and 3 audios, but using the maximum is rarely optimal. Start with the smallest set that controls the brief.

Seedance 2.5 preview routes observed through MuAPI expose a larger nominal budget. Treat that as capacity, not a recommendation.

## Real brand/product work

A clean orthographic or near-orthographic reference often helps more than a beautiful lifestyle image. For hard-surface products, prepare several views only when the shot reveals surfaces missing from the first view.
