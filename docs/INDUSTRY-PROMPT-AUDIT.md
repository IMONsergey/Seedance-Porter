# Global AI Video / Motion Design Prompt Audit — 2026-08-07

This audit is the research layer behind Seedance Porter's prompt library. The goal is not to scrape and republish other creators' prompts. The goal is to identify repeatable production patterns across first-party model guidance, large prompt galleries, award-oriented digital design, motion-design case studies and current AI advertising workflows, then convert those patterns into original, reusable Seedance-oriented templates.

## Scope

Audit date: **2026-08-07**.

Research classes:

1. First-party model prompting and camera guidance.
2. Prompt libraries / community galleries.
3. AI advertising and product-video tooling.
4. 2026 motion-design / SaaS / branding case studies.
5. Award-oriented interactive / web motion references.
6. Large prompt datasets and research.

The resulting library prioritizes **design, digital, product, SaaS, web hero, UI motion, branding, kinetic typography, packaging and case-study presentation** over generic cinematic landscapes.

## What the industry audit says

### 1. The high-value commercial category is no longer “generic explainer”

The clearest 2026 signal is the move toward **website hero motion, product launch, SaaS/UI sequences, brand identity motion and logo animation**. AI prompt libraries are still disproportionately cinematic / anime / meme oriented, so there is a real product gap for a design-first library.

### 2. Hybrid is stronger than “AI did everything”

The best design case studies repeatedly use AI as one layer inside a controlled pipeline:

- establish product / UI / logo geometry first;
- use generative video for motion, transitions, atmosphere or impossible shots;
- finish typography, UI, logo fidelity, sound and compositing in AE / C4D / Premiere / Resolve.

Seedance Porter should therefore label prompts by **post-production expectation**, not pretend every card is a one-click final deliverable.

### 3. Reference role discipline is a universal pattern

BytePlus, Firefly, Runway and current production workflows converge on the same idea: reference material works best when each asset has one clear job. The library exposes this as `referencePlan` on every relevant prompt.

### 4. Image-to-video prompts should not restate the image

Runway's current guidance is especially useful here: the image already contains subject, composition, lighting and style. For image-to-video, text should spend tokens on **motion, camera and temporal progression**. Porter templates therefore separate `visual brief` from `motion instruction` and mark which mode each prompt is designed for.

### 5. UI / SaaS video is a distinct craft

The strongest SaaS work does not simply point a camera at a floating dashboard. It uses hierarchy:

1. hero promise;
2. one interface action;
3. visual proof / state change;
4. device or environment context;
5. restrained brand endpoint.

The library includes dedicated prompts for dashboard macro, glass UI, product-tour transition, cursor-led navigation, data-to-interface transformation, device-to-screen transfer, app onboarding and UI/AI-avatar hybrids.

### 6. Camera vocab is a reusable design primitive

Camera motion is not merely cinematic decoration. In product/UI work it encodes information hierarchy: macro = material/detail, orbit = dimensionality, push-in = emphasis, lateral tracking = progression, top-down = system/composition, static = trust/clarity.

### 7. The best prompt library should be a remix system, not a clipboard dump

A useful prompt product needs:

- variables and defaults;
- filters by use case / category / motion / model mode;
- source provenance;
- “why it works” notes;
- reference plans;
- BOS/Seedance compatibility;
- copy resolved prompt;
- copy reusable template;
- create Porter project JSON;
- favorites / collections;
- conceptual preview images;
- clear distinction between source evidence and Porter-original adaptation.

## Library policy

1. **No wholesale prompt scraping.**
2. Prompts are Porter-original templates built from cross-source production patterns.
3. Every template links to one or more research sources.
4. Community prompt libraries are inspirations / taxonomies unless their license explicitly permits reuse; even then, Porter defaults to paraphrase + attribution rather than verbatim cloning.
5. Preview images generated by the web interface are labeled **concept previews**, not claimed model outputs.
6. The authoritative Seedance layer remains `BOS-2026-07-17`; industry patterns cannot override first-party BytePlus rules.
