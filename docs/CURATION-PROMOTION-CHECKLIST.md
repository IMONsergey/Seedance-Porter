# Promotion editorial checklist

Use this checklist before exporting a curated implementation draft.

- Full source video was watched and attested in the Deep Review.
- Candidate joins back to a real Research Corpus source record.
- Original creator/source attribution is resolved as far as reasonably possible.
- Source/usage provenance has been checked for editorial use.
- Published preview/player strategy has been verified.
- Named-IP / celebrity / trademark risk flags are cleared or the case is rejected.
- `whyItWorks` describes observed behavior, not requested prompt behavior.
- Verified signature move is supported by observed shots.
- Porter Adaptation was written independently from the mechanism.
- Source prompt wording was not copied.
- Source-specific product, identity, character, trademark and incidental location were removed from the transferable pattern.
- At least one Collection is editorially justified.
- Final draft still requires a reviewed repository implementation change.
